{% comment %} One way to show a long id (site-uuid, #618): the first 8 characters in mono plus a copy button for the full value, wherever an id appears in passing. For a dedicated Identifiers block, pass full=True to show the whole value instead (still with its own copy button). Needs static/js/copy_id.js (loaded site-wide in base.html). Usage: {% include "beetles/includes/short_id.html" with value=obj.id %} {% include "beetles/includes/short_id.html" with value=obj.id full=True %} {% endcomment %} {% if full %}{{ value }}{% else %}{{ value|stringformat:"s"|slice:":8" }}{% endif %}
