Model predictions

Upload an AI model's species guesses for ROIs. They appear as an unverified suggestion on ROIs that have no species label yet, and they set how hard the game treats each image. A prediction never changes an ROI's label.

The quickest way is the Upload model predictions action on Data management, which shows its progress as it saves.

record_idThe ROI's id (the record_id column of a gallery download). Leave it empty for a box the model found.
image_id, bbox_x, bbox_y, bbox_width, bbox_heightOnly when record_id is empty: the image and the box (fractions of the image, top-left corner). The same box already on the image is used; otherwise the box is added, with no species label.
valid_species_idThe predicted species, as in the species list. Required.
confidence0 to 1 (0.87, not 87). Required.
model_nameOr give one name for the whole file above.
model_versionOptional. Uploading the same model and version again replaces its predictions.
top_kOptional further candidates, best first: 1733:0.08;2210:0.03
subfamily, tribe, genusOptional: what the model said at that rank, each with a <rank>_confidence column (0 to 1), e.g. genus=Xyleborus, genus_confidence=0.92

The whole file is checked before anything is saved. If any row is wrong, nothing is saved and every problem is listed with its row number. For very large files, use manage.py import_model_predictions on the server.
