Species Tables

The two tables every name on the site comes from: labels, the game's name lists, uploads and the AI's answers. Uploading a new version replaces the current one (the old one stays in the version history) and re-links every beetle to it.

Accepted species: every species the gallery accepts, each with its ID (valid_species_id) and its place in the taxonomy (subfamily, tribe, genus, species). This is the gallery's ground truth: a beetle's name is one of these IDs.

Synonyms and old names: every name a species has been described or recorded under (synonyms, earlier genus combinations, spelling variants), each pointing to its accepted species (name_valid_species_id). Used to turn the name on a vial label, in an upload or from a model into the accepted species.

Update Metadata

Changes records that are already here, found by their record_id. Start from a download of the records (it has every column filled in) and edit only what should change: every cell is written, so a blank cell clears that field.

To add a box, fill the four bbox_ columns on the record's row. To add another beetle to an image, add a row with record_id = NEW and the image_id.

Size limit: the CSV must be less than 10 MB.

Data Dictionary / Field Definitions

{# Modal Content (Scrollable) #}
Field ID Description
full_path_at_import New uploads only. The image's path inside the ZIP (e.g. folder_1/image_001.jpg). Required. Rows with the same path are beetles on the same image.
record_id Updates only. The record (one beetle on one image) to change, from a download. NEW adds a beetle to the image given in image_id.
image_id Updates only. The image a NEW row belongs to (from a download). Ignored on other rows.
alias_id Your own ID for this record: a catalogue number, accession number or file name from your own database or files. Optional, and you never need to make one up. We keep it exactly as given and include it in every download, so you can always link our records back to yours (and update them by it). Files that still call this column alternative_id are accepted.
image_institution The institution to credit the photograph. This may not be the same as the institution which holds the specimen, or denote full usage rights.
photographer The person to credit for taking the photograph for the image.
image_email An email contact for enquiries about the image.
photo_usage_statement A statement relating to usage of the photograph, with terms of usage (e.g., specific terms or Creative Commons such as CC BY 4.0).
aspect The view depicted (e.g., dorsal, lateral, ventral, anterior, posterior) or specific parts (e.g., antennae, genitalia, labels).
resolution_in_ppmm The number of pixels per linear millimeter in the best focused area of the image (not the same as optical resolution).
image_notes Additional notes regarding the image.
image_date_taken Date when the image was taken (YYYY-MM-DD). Time is not stored.
image_has_multiple_individuals Whether multiple individuals are present. Accepted values: 0/1, True/False, or Yes/No.
depicts_specimen The specimen or biological sample identifier depicted. Only one value should be listed here (even if a sample ID refers to multiple specimens).
depicts_valid_name_id The species depicted, as its ID in the Accepted species table (valid_species_id). Leave blank if not identified.
depicts_described_name_id The name as written on the specimen or in the source, as its ID in the Synonyms and old names table. Mostly for type specimens and old labels.
depicts_name_verbatim A verbatim text name. Allows for original descriptions, unknown names, or ambiguous names.
taxonomy_scientific_name Read-only reference field showing the scientific name from the taxonomy database (for verification only).
taxonomy_subfamily Read-only reference field showing the subfamily from the taxonomy database (for verification only).
taxonomy_tribe Read-only reference field showing the tribe from the taxonomy database (for verification only).
taxonomy_genus Read-only reference field showing the genus from the taxonomy database (for verification only).
taxonomy_species Read-only reference field showing the species from the taxonomy database (for verification only).
bbox_x Bounding box X coordinate: the left edge as a fraction of the image width (0-1, not pixels). A box needs all four of bbox_x, bbox_y, bbox_width and bbox_height and must fit inside the image; leave all four blank for no box.
bbox_y Bounding box Y coordinate: the top edge as a fraction of the image height (0-1).
bbox_width Bounding box width as a fraction of the image width (above 0, up to 1).
bbox_height Bounding box height as a fraction of the image height (above 0, up to 1).
bbox_is_validated Whether the bounding box coordinates have been manually validated (needs a box). Accepted values: 0/1, True/False, or Yes/No. Leave blank to keep the current value.
collection_country The country of collection (DWC:country).
collection_stateProvince The state or province of collection (DWC:stateProvince).
specimen_sex Strictly restricted to: Male, Female, M, or F. For mixed groups, please use specimen_notes.
specimen_type_status Type status (e.g., Holotype). Include the status, full scientific name, and authority.
specimen_notes Additional notes regarding the specimen.
is_validated Whether an expert has checked the whole image and all its beetles. Accepted values: 0/1, True/False, or Yes/No.
label_source Updates only, optional. Where the species name came from: vial_label, taxonomist, external or game_consensus.
label_source_detail Updates only, optional. Who identified it, or which database or website (a name or a link).
update_notes Updates only, optional. A note on why the record changed, kept in its history.
