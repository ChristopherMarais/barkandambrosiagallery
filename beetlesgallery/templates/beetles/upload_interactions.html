How rows are read

record_idBlank or NEW adds an interaction. An existing record_id updates it. Required column.
records_idOptional, new rows only: the dataset's own number for a record (1–1015 in the published v1.0). Leave it blank for your own rows. It cannot be changed afterwards.
beetle_host / beetle_host_idThe beetle, by any name in the species list (a synonym is matched to its valid name) or its valid_species_id. Needed for a new row.
pathogen, categoryThe other organism, and Fungi, Nematode, Host plant, Mite ... Needed for a new row.
ecological_relationship, source, year, title, doi_or_full_text, country_or_region ...Optional. doi_or_full_text is a DOI or a web link. The year is four digits.
originIn the download for information; ignored on upload.
  • On an update, only the columns in your file change, and a blank cell empties an optional field.
  • The whole file is checked first. If any row is wrong nothing is saved and every problem is listed with its row number.
  • Interactions from the published v1.0 dataset cannot be changed here (the interactions page shows that dataset from fixed, versioned files). Ones you add, and ones accepted from proposals, can.
  • Adding the same beetle, organism and source twice is refused.
